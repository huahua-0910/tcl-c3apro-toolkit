# 首次用户与智能体复核

2026-10-21，0.1.1。基线为0.1.0发布提交 `4f0c989`。本轮仅审查公开项目，未连接或修改电视。

## 已发现并修复

| 缺口 | 修复与验证方式 |
| --- | --- |
| 端点变量未教如何设置、无成功条件 | 补bash/zsh与PowerShell输入方法，区分配对/连接端点，空值在调用ADB前拒绝。 |
| 只讲APK入口，下载和一致性检查不完整 | 指向固定发行页、摘要校验、U盘前提与页面出现的判断；无ADB时不使用adb安装作为前提。 |
| 未保存可用体检基线 | inspect增加--out、当前用户和包状态用户说明；明确每轮使用新文件名。 |
| ZIP下载后隐私扫描报Git错误 | 无Git时自动tree扫描；隔离源码树模拟ZIP操作并检查。 |
| 已暂存秘密可能被工作区清理掩盖 | 从Git index读真实blob；回归用合成假令牌复现，报告不回显值。 |
| 当前版本干净但历史仍可能含秘密 | 增加--history，检查所有本地可达引用中的文件blob；CI获取完整历史。 |
| Cookie/Authorization等模式未覆盖 | 补规则与合成测试；无法穷尽未知格式，人工审查仍保留。 |
| 原HOME是解析器/不可用候选时仍能变更 | 在保存事务与首次写入前检查原HOME可作为回退目标。 |
| 错误后写回执失败会跳过回退 | 设备恢复与回执写入分离；模拟磁盘故障仍验证恢复尝试。 |
| 成功变更后无法写最终回执 | 作为失败处理，尝试恢复原HOME；终端明确返回失败，避免无证据成功。 |
| enabled回退与DPC恢复窗口不够明确 | 增加原enabled数字对应的正常恢复方法；标明hidden恢复需在撤销管理身份前完成。 |
| Android命令的错误文本被丢弃 | 返回原始失败文本到本地终端/私人回执，停止并保留首次原因。 |

最初回归运行实际出现4个FAIL与1个ERROR，分别覆盖敏感头、暂存错位、ZIP、回执故障和原HOME保护。修复后在相同接口复验；首次失败不当作通过，不操作电视来修正测试结果。

## 可复验的演练

```sh
python3 -m unittest discover -s tests -v
python3 tools/audit_public.py --source tree
python3 tools/audit_public.py --history
```

本轮共27项测试通过；源文件树、真实暂存区及可达历史扫描无命中。托管CI以发布提交对应的GitHub检查为准。

CLI演练将当前源码复制到无Git/无旧state的临时目录，显式指定假ADB，依次运行inspect保存、base/split备份与SHA核对、HOME预览、apply、restore预览、restore执行、ZIP扫描和空端点拒绝。假ADB只接受fixture-device，根本不调用真实ADB。

原生Windows会跳过需要POSIX可执行脚本的完整CLI演练，WSL可运行；未装Git时只跳过Git专用夹具。

智能体按AGENTS.md应能找全路径、执行前提和验收条件；模拟全流程通过不能替代其他智能体独立试用或新用户实机验收。Git历史扫描只覆盖可达文件内容，不覆盖Git作者元数据、Release附件、issue或远端已删除历史。

本次改动不修改Android源码、不重签设置入口APK。0.1.0的APK及原始校验材料继续保留；本版发布为工具与文档更新。
